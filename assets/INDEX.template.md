## Prefixes

| Prefix | Between | Meaning |
|---|---|---|
| `AGENT-###` | member <-> member | Technical. The members settle it. The owner never needs to read these. |
| `ASK-###` | members -> owner | Non-technical, **and only after the members agree a recommendation.** |

**The rule that decides the prefix:** an `ASK-` thread may not be opened until
the members have discussed the matter and agreed what to recommend. If only one
member has looked at it, it is still an `AGENT-` thread.

## Writing an entry

**Scope: this log is for the project, not for how the log is kept.** Working
conventions belong in each agent's own instruction file, not in a thread.

1. One `threads/<ID>-<slug>.md` per topic. Reply inside that file.
2. Start every comment with `[Name, DDMM, HHMM]`, read from the system clock.
   Never invent a time. Write it with `.handoff/handoff.py reply`, passing long
   or quoted text as `--body-file <path>` or `--body-stdin` so no shell gets a
   chance to mangle it.
3. Preserve earlier comments. Append a separator and your comment; update the
   thread's `Status` when its state changes. Comments inside a thread stay
   chronological.
4. `Status` is a short token: `open` `answered` `blocked` `closed` `withdrawn`
   `superseded`. Reasoning goes in the comment body. The first three are live
   and stay listed above; `blocked` means the thread is waiting on something
   outside itself.
5. **Transcribe the owner's words verbatim**, attributed to them, placed before
   your own response. Quote exactly; keep your reasoning out of the quote. The
   members do not share the owner's conversation, so the thread is the only
   place anyone else can read what the owner actually said.
6. **Never assume a file contains only your own writing.** Re-read before
   editing; preserve changes you did not make.
7. Add your turn to the **top** of Conversation history, one row per speaker's
   turn. Run `.handoff/handoff.py sync` to rebuild the tables.
8. **Promote decisions into the specification or contract the same session.** A
   decision that exists only in the log does not exist.
9. Shared files use **ASCII punctuation** (`-`, `->`) so members on different
   providers stop rewriting each other's characters.

**Escalation:** technical -> the members decide. Non-technical -> the owner,
consolidated, with a recommendation. Machine actions -> the owner's approval at
the moment of acting.
